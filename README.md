# cbportfolio

Chetan Bharati - Video Editor & Motion Creator Portfolio website.

## Showcase Features
- Clean White Minimalist Studio Theme
- 8 Signature Video Works (Reels, Commercial Ads, Wedding Cinematic)
- Instant Sound Toggle & Full-Screen HD Lightbox Video Player
- Direct Instagram & LinkedIn Connect

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Lucide React
- Git LFS for media assets

## Run Locally
```bash
cd frontend
npm install
npm run dev
```
